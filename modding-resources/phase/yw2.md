# YW2 Phase Boundaries


| Phase               | Notes                                                                                                                        |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `10010`             | Start of Chapter One, "**The Vanishing Watch**".                                                                               |
| `20010`             | Start of Chapter Two, "**Hi-Tech Hide-and-Seek**".                                                                             |
| `20075`             | Unlocks the "**A Cicada Professional**" and "**Customer Attraction**" Quests.                                                  |
| `30010`             | Start of Chapter Three, "**School Is Strange**".                                                                               |
| `30095`             | Unlocks the "**Officially Official!**", **Bam-Boom! Fusing!**, and **The Gates of Whimsy** Quests.                             |
| `40010`             | Start of Chapter 4, "**Lets Go To Harrisville!**" Unlocks the "**Go for Rank C!**" with a D-Rank Watch.                        |
| `40135`             | Unlocks the "**Secrets of Soulcery**" Quest.                                                                                   |
| `50010`             | Start of Chapter Five, "**Wind It Back 60 Years!**".                                                                           |
| `60010`             | Start of Chapter Six, "**Yo-Kai Watch Model Zero**".                                                                           |
| `70010`             | Start of Chapter Seven, "**The Storm Is Here!**".                                                                              |
| `70020`             | Unlocks the **"Go for Rank B!"** quest.                                                                                        |
| `80010`             | Start of Chapter 8, "**Big Yo-Kai Battle**", unlocks **"Go for Rank A!"** and **"Eerie, Roving Armor"** with an A-Rank Watch.  |
| `90010`             | Start of Chapter Nine, "**Master Nyada's Trials**".                                                                            |
| `110010`            | Combined with a **Watch Rank of A**, this unlocks the **"Go for Rank S!"** quest.                                              |
