# File Format Specifications

This is a list of specifications for properietary file formats, binary structures and other systems created and used by Level05 in the Yo-kai Watch franchise. This is intended for a technical audience and *not* the majority of modders.

It is recommended to start on the [Signature](./file-formats/level5-sigs.html) and [Level-5 Compression Container](./file-formats/level5-compressed-container.html) pages before moving to the file format you wish to.
