# yo-docs

Bienvenue sur yo-docs, un site de documentation sur Yo-kai Watch.
Si vous voulez jouer à un mod, veuillez consulter la section [Jouer aux Mods](modding-guides/playing.html).
Si vous voulez en *créer* un, commencez par le guide [Bien démarrer](modding-guides/gettingstarted.html).
Enfin, si les glitches vous intéressent, jetez un œil à [cette section](glitches-and-exploits.html).
