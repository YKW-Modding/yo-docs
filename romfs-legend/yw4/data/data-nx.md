# nx-ps4/

This folder contains every texture. The folder contains:
* `chr` - Contains textures applied to the chr models. A full list of IDs for this folder can be found at [this game’s ParamID page](https://ykw-modding.github.io/yo-docs/modding-resources/param-ids/yw4-param-ids.html).
* `effect/` - Contains textures applied to various effect types.
* `event/` - Contains textures applied to special items in events.
* `font/` - Contains textures applied to different fonts.
* `map/` - Contains textures applied to the map models.
* `menu/` - Contains textures applied to the UI or other related overlays.
* `shader/` TODO - Seems to be files controlling various aspects of the shaders.
* `sound/` - Contains every audio file in the game.
