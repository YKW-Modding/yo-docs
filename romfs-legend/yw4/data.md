# data

This contains:
* `common` - This folder tree mainly consists of non-texture files.
* `nx/ps4` - This folder tree mainly consists of texture files. On the Nintendo Switch version, it will be `nx`, while on the PS4 version, it will be `ps4`.
* `cpk_list.cfg.bin` - This file lists the size and location of every file in the game.
